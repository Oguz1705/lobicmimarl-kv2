# LOBİ İç Mimarlık

## İçerik yönetimi
- Ana sayfa slider: `public/media/home-slider/` içine görsel ekleyin. Görseller otomatik bulunur; sayı sınırı yoktur.
- Ofis projeleri: `public/media/projects/ofis/`
- Ticari projeler: `public/media/projects/ticari/`
- Proje başlığı görsel dosya adından otomatik üretilir. Örnek: `01-banka-genel-mudurluk.jpg` → `Banka Genel Mudurluk`.
- Logo: `public/media/brand/logo.svg`
- Ana sayfa metinleri ve menü: `content/site.js`

Projeler sayfası: `/projeler`
